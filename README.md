# TestFlow 测试排程与耗时计算器

用于安排多站点测试，比较不同组织方式的总时长、等待人数与站点容量。

直接打开 `index.html` 即可使用。页面没有外部脚本依赖，可离线运行；方案保存在当前浏览器，也可保存为 JSON 文件。

## 功能

- 可收起的方案设置侧栏，四张结果卡片可自行选择展示指标。
- 个人流水线、全员逐站完成、分组同步轮转三种组织方式。
- 独立工位与整批测试，分别设置测试耗时、复位时间及最低离站间隔。
- 在指定站点或轮次全体完成后插入统一休息，完整测试不会被拆开。
- 自动分批到场，按起始站点开测顺序安排就位和提前准备。
- 站点及人员时间轴。悬浮查看鼠标所在时刻的测试人员、工位、剩余时间和等待人数；点击展开完整名单。
- 站点工作时长、工位使用率、平均与最长等待、峰值等待人数。
- 导出带样式的 XLSX：排程总览、人员排程、站点排程、到场安排。保留 CSV 原始数据导出。

## 计算口径

所有测试耗时最多保留三位小数秒。本站等待从个人满足最低离站间隔后算起，首站从本批就位时算起，到实际开测为止；包含排队、凑批和统一换站等待，扣除整体休息。转场、恢复和提前到场准备不计入。

人均累计等待时间先把每个人的各站等待相加，再除以人数。全场峰值等待人数按同一时刻等待测试的不同人员计算，各站峰值不能直接相加。区间使用开始包含、结束不包含的规则，结束等待与开测不会被重复计数。

工位使用率为本站实际占用工位总时长除以“人数上限 × 本站首次开测至最后测完的跨度”。整批测试按人数位置计算占用率。

自动分批到场沿用当前方案的人员顺序和测试时长，减少首站提前等待；它不是对所有组织方式的全局优化。以上结果基于设定时长和准时执行。

Excel 时刻列在填写开场日期后保存实际本地日期和钟点，未填写时保存距全场开场的累计秒数，负数表示开场前。测试与等待时长使用数值和时间格式，保留小数秒。导出文件对应当前方案，调整参数后请重新导出。

## 开发

模块位于 `src/`，生成后的单文件页面为 `index.html`。

```bash
python3 build.py
npm test
```

构建只需要 Python 3；测试只需要 Node.js 18 或更新版本，不需要安装 npm 依赖。`src/testflow-xlsx-template.js` 保存已制作的工作簿字体、配色、边框和布局模板，浏览器填充当前排程后直接生成标准 XLSX 文件。

支持最多 500 人、20 个站点及 20 段整体休息。桌面和移动端均可操作。
