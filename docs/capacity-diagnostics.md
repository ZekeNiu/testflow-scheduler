# 容量诊断：统一工作台迁移说明

自统一优化版本起，原“容量试算”不再是独立结果页签，入口、容量边界、手动试算、上限检查与确认应用都归入“方案优化”。
权威说明见 [统一方案优化工作台](plan-optimizer.md)。

保留的计算能力：使用正式排程引擎，区分独立工位与整批人数上限，单站试算结果不能直接相加。
新增多站容量与组织方式联合比较，不能因为某站单独增加容量无效，就推断不存在共同限制。

界面不再分别显示容量建议和容量瓶颈警告两块内容，只保留“方案检查与调整建议”。
超限与模型中的改善机会不等于证实资源不足。站点表保持事实数据，相关比较在统一工作台进行。

src/testflow-diagnostics.js 的原单站计算 API 和数值测试保留兼容；原扩展中的直接应用入口不在当前用户界面使用。
实际方案、导出格式及已有存储键不做破坏性迁移。
旧说明与旧测试可在 backup/before-unified-optimizer-20261002 查阅。
