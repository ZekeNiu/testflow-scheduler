# 自动方案分析与建议

本版本消除“必须先进入方案优化、再点击生成建议”的前置步骤。

## 用户流程

用户设置或载入有效方案后，结果页自动比较允许范围内的完整配置。
在原有“方案检查与调整建议”卡片中直接显示结论：有意义的组织或容量调整、预计收益、指标代价，或保留当前方案的具体理由。
卡片不是只给出上限状态再要求跳转。符合上限且值得采用的完整方案，可以直接在卡片打开原有预览确认窗口；不自动修改实际方案。

“方案优化”页签成为同一分析的细节编辑器。打开时复用已经算好的结果，不需要再次生成。
修改优先目标、可接受上限、允许组织方式或容量边界后，自动更新摘要和详细对比。
“重新分析”只用于主动重算或失败重试，不再是获得基础建议的必经操作。
手动容量试算和耗时波动情景继续保留，各自只在显式操作后计算；自动结果不会覆盖手动输入或手动结果视图。

## 触发与性能

在现有参数校验完成后，采用 450 毫秒输入合并等待；连续修改只计算最后的有效快照。
原排程更新有独立的输入合并逻辑。此处等待发生在页面内，计算不依赖外部服务。
自动搜索优先使用原有内嵌 Web Worker；不支持或无法创建 Worker 时，使用分段计算回退。
沿用已设最多配置数，不无限搜索，不放宽轮转、到场和资源权限。
无效参数或无效优化条件立即使旧的可操作建议失效；旧任务即使较晚返回，也不能替换新结果。
缓存最近四份相同方案及比较条件的结果，仅保留紧凑比较报告；视图、缩放、指标选择或窗口尺寸变化不重复搜索。
缓存键使用完整计算输入，包含其他候选可能使用的隐藏到场准备参数；每份报告绑定输入键，预览和应用重新计算候选及指标。
自动完成不重新渲染设置表单、不移动输入焦点、不主动滚动页面。
手动计算优先，期间暂停未完成的自动计算。可主动暂停自动分析；同一配置的视图切换不会让暂停失效，修改实际方案或重新分析后恢复。

## 安全与科学边界

使用同一个正式排程引擎、完整候选方案和评价规则，不新建一套近似评分替代原计算。
默认不增配、不默认允许改变测试起点；未核实跨站资源时仍显示适用前提，确认应用要求核实规程。
已明确存在跨站共享资源时暂停建议计算和应用，不声称排程已验证该资源冲突。
手动与自动遵守同一套上限；不把未达标结果当成可直接采用的建议。
完整覆盖声明配置才给出范围内最优结论；限量结果明确未完全覆盖，不证明全局最优或无可行解。
主目标没有明显改善时保留当前方案为默认；显著的次级收益和不利变化会直接显示，并提供完整辅助方案对比入口。
已知共享资源声明不随人数或耗时等一般编辑清除。

当现有容量下没有值得采用的改变时，可展示一项达到提醒阈值的单站容量参考。
这种参考是“如果增加容量”的假设，不代表已确认存在设备或人员；与正式推荐分开，不能直接确认应用。
说明增加容量后可能出现的等待代价，并保留“相对当前方案、不同收益不可相加、自动到场随容量重算”的口径。
核对容量入口只帮助用户填写实际边界，不擅自把参考值写入实际方案。

## 兼容与样式

继续使用原有建议卡片、按钮、配色、细边框与关闭状态，不增加第二块相同提示，不恢复站点表重复标签。
已关闭的卡片不会因自动计算完成、修改比较偏好、刷新或切换页面重新打开；实际方案变化后才按原规则更新关闭状态。
原有数据版本、存储键、时间轴和人员明细保持兼容。到场按波次计数并另列接待组；JSON 增加可选优化上下文，CSV 和 Excel 同步明确新口径。
预览、显式确认、一次性应用及撤回保护沿用统一工作台。
